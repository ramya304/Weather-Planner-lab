# Weather Planner 🌦️

## About the Project
Weather Planner is a beginner-friendly Python project created as part of the freeCodeCamp Python course. It uses distance, rain conditions, and available transportation options to decide whether a particular travel option is suitable.

## Features
- Checks the travel distance.
- Considers whether it is raining.
- Checks bike, car, and ride-sharing availability.
- Uses conditional statements and logical operators to make decisions.

## Python Concepts Used
- Variables and data types
- `if`, `elif`, and `else` statements
- Comparison operators
- Logical operators: `and`, `or`, and `not`
- Boolean values (`True` and `False`)

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in PyCharm or a terminal.
4. Run the Python file:

```bash
python main.py
```

## Learning Outcome
This lab helped me practice Python conditional logic and understand how multiple conditions can be combined to make decisions in a simple, real-world scenario.
